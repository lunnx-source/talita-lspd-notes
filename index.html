Response Codes & Radio Usage 🎙️
  • Code 1: Non-emergency response: tidak pakai sirine dan lampu ratatoar.
  • Code 2: Emergency response: hanya menggunakan lampu ratatoar.
  • Code 3: Emergency response: sirine dan lampu ratatoar menyala.
  • Code 4: situasi sudah aman.
  • Code 5: Detective under investigation.
  • Code 6: melakukan investigasi/pencarian baik di dalam kendaraan ataupun on foot.
  • Code 7: Meal Break.

How to Use 10-Codes / Response Codes on Radio 🚨

Patroli Reporting:
"Dispatch, this is 72ADAM505 doing 10-08 at municipal area, ready for any situation."

Updating reporting dari 55 berubah menjadi pengejaran 57:
"Dispatch, for the last 10-55 situation on [nama jalan], it's now changing into active 10-57 (pursuit). Requesting 10-78 (backup) on my 20 (location). Suspect is now heading (arah pelarian)."

Detail: "Suspect is now heading West on Vespucci Blvd, taking left, heading South on San Andreas Ave."

Update structure, Talita preference:

  • Action (Tindakan) - contoh: heading / belok kiri
  • Arah mata angin - North / South / East / West
  • Nama jalan - Lokasi atau jalur
  • Informasi tambahan (opsional) - landmark, lalu lintas, deskripsi suspect

Pursuit Behavior - Unit Roles ⭐

  • Primary Unit: Mobil utama yang akan mengejar.
  • Secondary Unit: Membantu komunikasi dan call-out.
  • Alternate Unit: Siap untuk block road atau deploy spike strip.

Selama Pengejaran: Memberikan update berkala (arah, kecepatan, situasi lalu lintas), serta menjaga jarak aman dan tidak saling menabrak.

Taktik Khusus: Spike Strip, PIT Maneuver, Box Car. *(Hanya boleh dilakukan dengan izin dari IC atau Sergeant).*

Incident Commander (IC) Protocols 📢

Menurut Talita, sebagai Incident Commander (IC) hal yang terpenting adalah tegas. IC diberikan kewenangan tertinggi dalam suatu insiden, sehingga segala hal yang terjadi harus dalam sepersetujuan IC.

Tanggung Jawab IC di Crime Scene

  • Wajib double check apakah seluruh evidence telah terkumpul (crime scene evidence, run plate, dsb).
  • Menentukan pursuit line up: siapa yang akan menjadi primary, secondary, alternate, dan juga securing hostage.
  • Catat semua kejadian dan jangan lupa melengkapi mdt selengkap lengkapnya.

Selama Pengejaran

  • Sigap atas segala perubahan dan tindakan suspect.
  • Jika tindakan suspect membahayakan warga atau sudah break the demand, IC harus memperhitungkan penggunaan spike trap atau PIT maneuver.
  • Take tire hanya dilakukan jika situasi sudah tidak kondusif.

Komunikasi & Ketegasan

  • Jangan takut menegur unit yang melakukan kesalahan.
  • Jika ada officer yang menginterupsi radio dengan informasi tidak bermanfaat, IC harus tegas mengatakan "10-3".

Setelah Situasi Terkendali

  • Pastikan semua suspect diproses sesuai prosedur.
  • Pastikan MDT (Mobile Data Terminal) diselesaikan dengan rapi dan lengkap.

"Seorang IC harus tegas, sigap, menguasai situasi, berani mengambil keputusan, dan tidak takut menegur. IC bukan sekadar Role, tapi tanggung jawab penuh atas jalannya sebuah insiden"
